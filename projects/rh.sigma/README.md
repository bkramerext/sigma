# Riemann Hypothesis example project

This is a source-controlled **starter project**, not a completed or verified investigation. `config.json` defines the research problem. SIGMA initializes local mutable state in `state.db` when opening this starter project for the first time; the database and generated artifacts are not committed. No proof of the Riemann Hypothesis is claimed.

Open this directory from the local SIGMA web interface or via the CLI. Both use the same application services.
