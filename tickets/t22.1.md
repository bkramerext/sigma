# T22.1 Cloud architecture feasibility

Owner: ChatGPT. Status: In progress.

Goal: Validate Cloudflare Containers for FastAPI and SageMath, persistent state in D1/R2, and recoverable background jobs for three users.

Gates:
1. Deploy a minimal FastAPI container behind a Worker.
2. Run representative SageMath computation and measure memory, image size and startup.
3. Validate isolation of generated Python/SageMath from credentials, network and other users. Existing Docker CLI sandbox cannot be assumed to work inside a container.
4. Verify durable job recovery and no automatic replay of ambiguous provider calls.
5. Verify atomic D1 revision and budget claims under concurrency.
6. Verify hosted model authorization separately from Google sign-in.

Working direction: Cloudflare Worker, FastAPI Container, D1 metadata, R2 artifacts, short-lived isolated compute Containers. Keep local filesystem mode unchanged. If secure scientific isolation fails, use a conventional sandbox compute host.

UX: A server-backed running-session pill immediately left of existing header pills on Home and Project pages.

No paid deployment or model calls in automated tests.

Sources: https://developers.cloudflare.com/containers/platform/limits/ and https://developers.cloudflare.com/containers/faq/.
