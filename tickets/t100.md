# T100: Complete local validation of production-compatible persistent storage

Owner: Red · Priority: critical for Oct 26 launch · [GitHub issue #100](https://github.com/bkramerext/sigma/issues/100)

## Scope and architecture

Add an explicit `SIGMA_STORAGE_BACKEND=local|persistent_disk` switch (default
`local`) and an absolute private `SIGMA_STORAGE_ROOT` required by
`persistent_disk`. Reuse the existing POSIX/SQLite cloud workspace services for
local and GCE persistent storage. Keep normal LOCAL storage behavior unchanged.
Do not introduce GCS/gcsfuse or use GCP/paid inference for local parity checks.

Persistent mode requires authenticated owner workspaces. Auth DB, workspace
mapping, project/session/evidence/artifact files, Recents, research accounting,
experiments, and paper data must remain under the validated root. Configuration
errors, missing/mis-mounted disk, symlinks, unsafe ownership/permissions,
traversal, and corrupt mapping fail closed without falling back to LOCAL data.
The existing GCE override passes the mode/root, and host startup checks the
state disk mount before Compose starts.

## Acceptance

- Deterministic offline multi-subject acceptance exercises projects, strategies,
  sessions/evidence, Recent, exports/papers, ownership, restart, research spend
  accounting, and whole-root backup/restore to a fresh private directory.
- Negative tests verify unsafe/missing roots, mount, permission, symlink,
  traversal, and corrupt mapping behavior; normal sample/project data remain
  unchanged.
- Real Chrome opens a stock sample as a separate project, edits project details
  and a strategy, saves, reloads, reopens, checks IDs/content/Recent and stock
  sample immutability, repeats after backend restart, and proves another
  simulated authenticated subject cannot read or edit it.
- Docs provide the local fixture procedure. Run `env -u
  SIGMA_CLOUD_BOOTSTRAP_ADMIN_EMAIL ./sigma test`, focused tests, Compose config
  and local container smoke where Docker is available. No real OAuth/GCP required.
- Dedicated Red PR linked to #100; no self-merge.
