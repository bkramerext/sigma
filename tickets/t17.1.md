# A17.1: Project and Strategy Titles, Disclosure, and Research Controls

**Status:** Ready for Codex. **Priority:** UI correction and consistency pass after A17. **Scope:** Surgical changes to the existing application; no redesign.

## Intent

Restore the established SIGMA navy/copper styling and reduce UI clutter. Project, Strategies, and Sessions reuse the application's existing heading, table, row, and inline-edit conventions. Consistency, not invention, governs this correction. The **Strategies** section has compact top-level Play/Pause controls for the research process. Preserve all working A17 research-session behavior, backend safeguards, data, and artifacts.

**Read** `AGENTS.md`, `docs/PROJECT.md`, `docs/DECISIONS.md`, `docs/STATUS.md`, `docs/HUMAN-AI-INTERACTION.md`, and A17 first. Inspect the actual current UI and existing components before editing. Do not interpret prior generated mockup images as approved design specifications. Existing application styling is authoritative.

## UI changes

1. **Project heading and title:** Add a separate all-caps **PROJECT** section heading above the project title, styled and aligned consistently with the existing **STRATEGIES** heading. No `Project:` prefix or separate prefix control. Dedent the project heading slightly relative to its description as appropriate to the existing section hierarchy. Remove the Project expand/collapse arrow and disclosure behavior. Display the project title in place with a pencil; activating the pencil replaces the title *at that exact location* with an inline editor and **Save / Cancel** (hide pencil while editing). Do not open a separate edit control below, overlay, or modal. Keep the full description beneath the title; remove redundant truncated description beside it. Preserve existing project actions and description editing.
2. **Strategy table rows:** Reuse the existing Strategies table layout and **STRATEGY** column heading. Display each strategy title plainly in its existing row: no `Strategy:` prefix and **no expand/collapse arrow**. The pencil edits the title *in place*, replacing it with the same inline editor and **Save / Cancel** pattern as Project, hiding pencil while editing. Do not open an overlay/modal or move the editing surface. Retain access to strategy descriptions and existing actions through established UI patterns, without adding new controls or hiding content behind a removed disclosure. Remove previous/next navigation arrows. No extra explanatory copy or Add strategy button; existing New / Generate remains the creation entry point.
3. **Strategy titles throughout workflow:** Titles are explicit persisted fields, not computed from the description. Support them in strategy generation drafts, review, explicit Save strategy, subsequent edit, reload, and display. Encourage concise, bounded-investigation titles in generation instructions and validation. Preserve existing strategy IDs, descriptions, revisions, provenance, artifacts, and prior strategies. For legacy strategies without a title, use a deterministic, non-destructive display fallback; do not overwrite the description or silently migrate history.
4. **Top-level Strategies header:** Add small, existing-style **Play** and **Pause** icon controls aligned to its right. These are for the overall research process, **not** controls on each strategy. No strategy-selection dropdown or giant Start investigation button. SIGMA, not the user, selects which eligible strategy to investigate. Reuse A17's authoritative session start/pause/resume state, budgets, identity checks, idempotency, error toast and reconciliation. Do not implement an unbounded scheduler or automatic multi-session chaining in this UI correction. Play should initiate/resume a single bounded session through the existing backend; Pause should pause the active session. If autonomous selection is not yet supported, add only the minimal deterministic selection/validation needed and document the rule; never silently select a different strategy while one is actively bound. Disable unavailable actions truthfully. Do not invent model costs or completion claims.
5. **Sessions section below Strategies:** Move Sessions **below** Strategies, not between Project and Strategies. Use the **same heading and table conventions** as Strategies: **Sessions** heading, a right-aligned static count with correct singular/plural (`0 sessions`, `1 session`, `2 sessions`), all-caps **SESSION** table header, and rows titled `Session #1`, `Session #2`, etc. Each session row is collapsible to inspect its actual activity, findings, critiques, cycles, and artifacts, but do not wrap the section in a separate nested bounded panel/card. Reuse the existing table disclosure pattern and status indicators rather than inventing a different presentation. Session rows are primarily for inspection; research starts through Strategies Play, not a competing Start button in Sessions. Preserve A17 durable session identity, history, lifecycle and artifact inspection.
6. **Strategies heading actions:** Position existing **New / Generate** controls immediately **to the left of** the static `n strategies` count on the right side of the Strategies heading. Keep the top-level Play/Pause controls compact and distinct, with spacing/alignment following existing controls. No extra row or invented action bar.\n7. **Connection activity indicator:** In the existing ChatGPT connection pill, subtly pulse **only the existing green status circle** while one or more actual AI/provider requests are active (including research-session calls). Solid green when connected and idle. Track overlapping requests accurately; do not stop the pulse until all active requests terminate, and reconcile completion, failure, timeout, cancellation and disconnect with actual request state. Do not animate a disconnected/non-green status as connected. Honor reduced-motion preference; preserve the pill's existing dimensions, styling and wording. No fabricated progress or provider status.\n8. **Styling:** Reuse existing classes/tokens and icon sizes. Do not change palette, borders, typography, general spacing, navigation, or global layout. No new mockups, dashboard cards, commentary text, or other UI features.

## Interaction and correctness

- Pencil click and keyboard activation enter title editing **at the displayed title position**, without changing the surrounding layout or opening an overlay; Save persists; Cancel restores previous title. Hide pencil during editing. Blank/invalid title is rejected with actionable feedback. Failed save leaves user content intact and uses existing toast/error handling.
- Do not introduce Project or Strategy disclosure arrows or collapse behavior. Any existing Session-row disclosure remains keyboard accessible with accurate expanded state. Editing titles must not lose unsaved description edits or change research-session strategy snapshots silently; preserve A17 guards and require explicit handling of revision mismatch.
- Play/Pause reflect actual backend state, including pending, completed, stopped, interrupted, and disconnected states. Never claim a provider call was canceled or paused without confirmation. A17's bounded call cap remains intact.
- Preserve existing New Generate, strategy editing, Markdown display, project controls, artifacts, and session history.
