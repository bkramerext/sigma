# T22.5 - Per-user cloud research spending limits

Status: SPECIFIED, NOT IMPLEMENTED. Parent: T22. Required before external users can access paid cloud inference.

## Initial external-evaluation policy

Five invited accounts including the administrator. Each starts with a total $2 estimated inference allowance for the pilot. The global inference ceiling is $15 total, leaving $5 reserved for operator-directed testing and unresolved provider charges. No automatic monthly reset or user billing. Session limits: at most $0.25 estimated cost, six model calls, 15 minutes, one running session per user, two queued per user, and two running globally. All amounts and limits are proposed operator-configured launch values and require actual approval before enabling paid inference.

## Required implementation

Green's current Gate B branch has a global USD ceiling and per-user token budgets, but does not yet have a cumulative per-user USD ceiling. Add a durable per-user limit using authenticated workspace ownership, configured by SIGMA_CLOUD_USER_SPEND_CEILING_USD. Every dispatch must atomically reserve against both the user's remaining allowance and the global remaining allowance. Unknown provider outcomes must retain their reservations; never interpret unknown charges as zero or silently retry them. Revocation, restart, sign-out, new projects and changed account email cannot reset a user's spent or held allowance. Reject invalid or missing limits safely. Cloud guest accounts can never dispatch inference.

Show an owner-only budget summary: allowance, held or estimated usage, remaining, and unknown attempts. Exhaustion must block new calls with a clear message while allowing read-only access to saved research. Administrative exceptions must require authenticated audited authorization, never writable public parameters. Preserve local SIGMA behavior and separately deny unaccounted cloud inference routes.
