# T209 — Current Understanding AI strategy suggestion, copy-only

## Goal

Replace “Continue from Saved Evidence” with an explicitly requested, ephemeral
AI Markdown strategy suggestion inside Current Understanding. The researcher
alone decides whether to copy, edit, create, or ignore a strategy.

## Requirements

- Place **Suggest a Strategy** after the Current Understanding synthesis, inside
  its collapsible section.
- Return at most one Markdown strategy description and concise rationale,
  grounded in the project question, cross-session Current Understanding,
  bounded relevant evidence, and all existing strategies including disabled
  strategies. Preserve uncertainty and contradictory evidence, and distinguish
  conjecture, computation, and proof. Cite evidence IDs when supplied.
- Allow a no-additional-strategy result. Render an available suggestion with the
  existing safe Markdown renderer inside a collapsible text block and the
  standard Copy to Clipboard control.
- No dialog, close action, or automatic strategy mutation. Do not alter project
  identity, saved sessions, evidence, provenance, or strategy controls.
- Remove the saved-evidence strategy proposal/approval UI and its mutating API
  route. Preserve historical continuation records and Play/session continuation.
- Use the existing explicit provider/billing binding, cost accounting, context
  limit, and failure handling. No provider call occurs until the researcher
  requests a suggestion.

## Verification

- Mocked provider tests cover evidence/context selection, no-new-strategy,
  provider failures, cost/binding limits, and project nonmutation.
- Real-browser check covers nesting, Markdown display, collapse, copy control,
  and no strategy mutation.
- Run `./sigma test` and record exact outcomes in `docs/STATUS.md`.
