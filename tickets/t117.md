## Objective

Address the independently investigated release-safety and test-reliability
findings recorded in [issue #117](https://github.com/bkramerext/sigma/issues/117).
Keep the changes offline. Do not provision GCP, make paid provider calls, or
execute the GCE installer from tests.

## Acceptance

- The GCE host test cannot launch `install-gce-host.sh`; quoted and unquoted
  Ubuntu 24.04 identities pass a separately testable guard, while Debian and
  Fedora identities block. The installer calls that guard before package or
  filesystem mutations.
- The preflight's exit 1 versus 2 behavior is covered separately: a matching
  but unready Ubuntu host reports `FAIL`/1, while an unsupported host reports
  `BLOCKED`/2.
- UI lifecycle tests are isolated from inherited Google sign-in environment.
- `sigma test` continues read-only independent checks after ordinary failures,
  summarizes every failure, preserves a nonzero result, and skips output/build
  steps after failure. It refuses test plans outside its known check set.
- Ruff covers deployment and support code. Lint includes browser checks and
  evaluation scripts; format checks include `deploy/` and `scripts/` without
  reformatting the legacy browser acceptance suite or evaluation exports.
- CI explicitly runs on Ubuntu 24.04, checks the host regressions before the
  aggregate suite, and verifies the runner is non-root.

## Findings and limits

The second preflight failure was distinct from the installer guard. In a
controlled Ubuntu 24.04 fixture, failed host-service/command checks produce
`FAIL` and exit 1 as designed. The prior local-preflight test instead assumed
all results would be `BLOCKED` on every platform; it is now based on a Debian
fixture and no longer inspects the actual CI host.

The `stop_servers` assertion reproduces with this shell's exported
`SIGMA_CLOUD_BOOTSTRAP_ADMIN_EMAIL`; the assertion passes when that variable is
unset. The lifecycle test now clears the bootstrap and paired OAuth values for
its ordinary local-startup cases.

Ubuntu CI run #436 passed on prior PR head `fabf591`. The latest main sync
brought in an executable bit on `scripts/increment15_readiness.py` without a
shebang; the bit was removed because CI invokes the script through Python.
After that narrow fix, the full suite passed locally, with Ruff covering 107
files, plus Pyright, frontend typecheck and build. Ubuntu Actions run #443 passed at final code head `48be67f`, including focused
host/lifecycle checks and the full repository verification. Green's UI changes from current main were preserved. This
workstation is macOS, so live Ubuntu package installation, systemd setup, and
rootless Docker remain unverified. The installer was never executed. Elapsed time: about 45 minutes.
