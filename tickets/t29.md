# T29 — Human intervention in active research sessions

**Owner:** Blue. **Status:** Pending after T27. **Priority:** Next Blue work.
**Recommended model:** Luna Medium.

## Goal
Allow controlled human intervention while concurrent agents are researching, with correct state, budgets and auditable provenance.

## Scope
- Support bounded user guidance to an active session without rewriting prior agent outputs or corrupting parallel strategy runs.
- Define when guidance is accepted, queued, rejected or superseded and which agents receive it. Record user instruction, time, session/strategy/cycle targets and acknowledgment/uptake.
- Maintain truthful cancellation, pause/resume and restart behavior. No hidden extra model calls or automatic billing fallback.
- Provide the smallest usable existing-UI integration; coordinate any significant UI changes with Gray and obtain product approval before a UX redesign.

## Acceptance
- Tests for concurrent handoffs, timing races, cancellation, restart/recovery, repeated guidance and provenance.
- A deterministic scenario demonstrating the user instruction affects a later agent step, without retroactively changing history.
- `./sigma test`, focused browser/CLI checks and explicit limitations; no paid live-provider calls without approval.
- Blue opens PR for ChatGPT review; no self-merge.

## Dependencies
