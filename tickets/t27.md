# T27 — Research intelligence and agent guidance

**Owner:** Blue. **Status:** Assigned; ready for implementation. **Priority:** Immediate.
**Recommended model:** Luna Medium; escalate for concrete reasoning/orchestration blockers only.

## Goal
Make multi-agent research materially better through useful cross-strategy handoffs, history-aware investigations, skepticism and precise tool guidance. This advances, but does not automatically close, T17.8.

## Scope
- Inspect the existing Investigator, Skeptic, coordinator and handoff flow. Identify failures where information is available but not used.
- Make agents consume relevant evidence from sibling strategies and prior sessions, including failed attempts, assumptions, limitations and computational results. Preserve narrow, local strategy objectives and durable history.
- Prevent false transfer: challenge domain/assumption mismatches, incompatible definitions, unsupported generalizations and stale evidence. Skeptic should distinguish computational observations from proof.
- Improve role guidance and capability advertisement for currently available tools, including Python. Coordinate the eventual SageMath interface with T26; do not implement Green's sandbox or promise Sage before available.
- Preserve budgets, cancellation, provider error handling, provenance, persisted sessions and existing API contracts. No new UI or implicit provider billing fallback.

## Acceptance
- Deterministic multi-strategy scenario where a relevant handoff changes a later agent decision, with provenance identifying consumed evidence.
- Multi-session scenario where an earlier failure changes a subsequent bounded investigation; evidence history remains intact.
- Adversarial scenario rejecting an attractive but invalid cross-strategy transfer; explicit assumption mismatch and uncertainty retained.
- Tests showing correct tool guidance, absent/unavailable tools and Python computation interpreted as evidence rather than theorem verification.
- Compare outcomes against baseline where feasible; distinguish passing tests from live-provider research effectiveness.
- Run `./sigma test`, focused integration tests, and report any live validation not performed. No paid provider calls without approval.
- Blue opens an implementation PR; ChatGPT reviews and merges. Do not self-merge.
