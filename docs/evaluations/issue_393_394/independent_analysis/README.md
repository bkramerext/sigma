# Independent offline federation analysis

This is an independently prepared, source-grounded analysis artifact for the Issue #394 experiment. It is not generated from a SIGMA Investigator/Skeptic session, and no live or paid provider call, campus workload trace, benchmark, or deployment is represented. The manuscript uses published MindRouter deployment quantities, public scheduler/pricing/research sources, calculations reproduced from the checked-in scenario, and explicitly hypothetical university costs and success probabilities.

The two PDFs compile from the same `paper_body.tex`; the standard version sets `\ShowDiagramsfalse` and the second sets `\ShowDiagramstrue`. The explanatory tables and prose are the same in both. Diagram variants add only a policy-boundary diagram and a synthetic optimization frontier. Each figure caption identifies its proposed or hypothetical status. PDFs were built locally with Tectonic 0.17.0. The standard version is six pages; the diagram version is seven pages. Tectonic downloaded TeX support packages during compilation; no inference provider was called and no cost was incurred.

The primary published deployment source is Sheneman, *MindRouter: Open-Source LLM Inference Gateway for Institutional AI Sovereignty*, PEARC '26, DOI 10.1145/3785462.3815861, with the author-hosted paper linked in the manuscript. Other references and their scope are listed in the bibliography. In particular, the PEARC report's energy is not asserted to have been metered across the exact 17-day token window, its API-equivalent amount is not treated as quality-matched savings, and no published source here establishes university federation capability.

The reproducible calculations are in the repository's `research/sovereign_scenario_hypothetical.json`, `scripts/sovereign_cost_model.py`, `scripts/mindrouter_empirical_envelope.py`, and `research/sovereign_lp_optimization.py`. Standard-library regressions are `tests/sovereign_cost_model.py` and `tests/mindrouter_empirical_envelope.py`; both are part of `./sigma test`. The optional LP values were independently rerun using SciPy 1.17.0 in a transient `uv` environment, without changing the project lockfile. This is an offline analytical paper and does not satisfy the end-to-end requirement for real saved Investigator/Skeptic evidence.
