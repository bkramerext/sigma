# TeX paper dialog screenshots

`before-desktop.png` is the owner-provided dialog before this cleanup.
`after-desktop.png` and `after-mobile.png` show the completed paper preview
with the content contained in the dialog's scroll area. `authoring-progress.png`
shows the simplified in-progress status with the inline Cancel action.

14px, removed the redundant disabled Authoring button, aligned Cancel beside
progress, and added the export-matching “Open in browser tab” choice.
