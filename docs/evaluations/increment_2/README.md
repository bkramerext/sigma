## Actual Chrome journey

`browser_checks/current_understanding.py` uses installed Chrome 156.0.8078.47,
real API/Vite processes, an isolated auth/state root and blocked external provider
transport. It reads the retained exercised projects; it does not fabricate archive
history. The machine-readable [observation ledger](browser-observations.json)
records the implementation revision, source hashes, current IDs, focused artifact
targets, widths and zero-inference/page-error results.

For each project it:

1. Opens from Home and checks the three current-understanding groups.
2. Checks the actual historical finding/resolution or accurate empty state.
3. Navigates to a current and earlier source, checking exact artifact focus plus
   expanded session, evidence section and artifact disclosure.
4. Checks document fit at 1440px, 390px and 320px; reloads and checks stable state/IDs.
5. Downloads actual Project Audit JSON through the UI, compares its content with
   the baseline export, and retains the downloaded bytes and current-state response.
6. Confirms original source file bytes are unchanged and cleans up its servers.

## Tests and reproduction

```sh
uv run python tests/research_state.py
uv run pyright
npm --prefix frontend run typecheck
uv run --with playwright python browser_checks/current_understanding.py
env -u SIGMA_CLOUD_BOOTSTRAP_ADMIN_EMAIL ./sigma test
```

The browser driver requires the retained copies; set `SIGMA_STATE_CHECK_PROJECTS`
to an explicit owned project root if relocated. Complete audit exports remain
available for independent source inspection even where those original temporary
paths are unavailable. The export-only capture instrument is
[export_projects.py](exports/export_projects.py).

Focused tests cover typed read-only projection, original archives and clearly
labeled minimal synthetic schema fixtures: exact ID-linked closure/reopening,
narrative-only notices, unrelated and complementary claims without contradiction
inference, explicit sourced claim relations, dangling/foreign/future references,
duplicated identities, stable order, running/failed/empty history and project-path
isolation. The standalone read must not invoke recovery or provider transport.

[Full final offline test output](full-suite.txt) and [final Chrome output](browser.txt)
record actual commands/results. An earlier full run reached Pyright and caught a
test's unchecked optional source pointer; the assertion was guarded and the final
suite rerun. No failing run is represented as passing.

## Deliberate limits

“Current” is the latest saved reviewed local finding per strategy, not a semantic
ranking of proof validity. Source text, old mistakes and raw codes remain intact.
Unlinked legacy notes remain visible but are not blindly recycled as mandatory
work. Unmatched IDs and missing evidence are counted as uncertain, not resolved.
No provider prompt archives are mined to invent identity relationships. T48's
existing separate Conclusion behavior is unchanged; the new projection itself
never declares contradiction, equivalence or supersession from text inequality.
No fork-prefill or HTML/TeX-paper integration is included in this increment.
