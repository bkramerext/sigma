## Delivered

Expanded `browser_checks/t91_packaged_compose.py` to compile deterministic saved
TeX with the actual packaged Tectonic binary, save through the real paper archive
service, fetch through the authenticated API, parse strictly with `pypdf`, and
check the extracted page text. The malformed input contains an undefined TeX
control sequence and must return the explicit compiler failure while archive
files stay identical. The workflow compares source, PDF and generated HTML
report hashes after backend container recreation and after backing up the
stopped auth/workspace volume and restoring to a fresh named Docker volume. It
checks project/strategy/session/paper identity, outcomes and evidence, and
repeats user B denial after restore. Invalid tar extraction is asserted to fail;
restore success is recorded only after all valid-restore checks pass.

The full acceptance matrix is in [T91.2 evidence](../docs/evaluations/t91.2/README.md).
Requested criteria: PASS 5, FAIL 0, BLOCKED 0. Extra packaged workflow checks
also passed. The separate cloud-only persistent disk/GCP, Google OAuth, and
provider-inference checks are explicitly skipped/excluded.
