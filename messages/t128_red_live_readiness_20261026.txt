The host-only preflight ran rootless Docker as root and passed a bare socket
path to `docker --host`. Docker interpreted it as `tcp://localhost:2375/...`,
so live checks falsely failed despite a healthy rootless daemon. The checker
now runs the read-only Docker info/image-inspect commands as `sigma-sandbox`,
clears inherited Docker host/context variables, and passes an explicit
`unix:///run/user/<uid>/docker.sock` endpoint. The regression test asserts the
execution identity, sanitized environment, and endpoint.
