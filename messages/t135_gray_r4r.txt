## Implemented

- Added a standalone systemd installer, daily persistent UTC timer, snapshot service, and failure journal hook. The job stops `sigma.service`, checks no SIGMA Compose containers remain, verifies `/srv/sigma-state` resolves to the configured GCE block device, syncs the mounted disk, creates a labeled snapshot, waits for `READY`, and only then prunes managed points beyond the configured retention. Retention rejects values below 14; only points labeled by this backup and sourced from `sigma-state` are eligible for deletion.
- The job writes success/failure markers and restarts the application after the run when it was active before the job. The source disk is read-only inside the backup unit.
