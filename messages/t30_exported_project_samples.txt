validates SIGMA export v2, sanitizes private data, and creates an entry consumed

project and rebinds project identity/path for imported research session and
agentic evidence. Available histories, outcomes, computational source/output,
and provenance survive. Existing source projects remain unchanged.

Limitations: export v2 contains computation metadata and available previews but

recognized user home paths; it cannot reliably identify arbitrary unlabeled
secret-like prose.
