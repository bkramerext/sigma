IMPLEMENTED

- Preserved SIGMA's existing Investigator/Skeptic research-session and project
  persistence model. The existing project session records remain authoritative
  for lifecycle events, checkpoints, model outputs, Python/Sage evidence and
  outcomes.
- Added a workspace-owned SQLite ledger beside private workspace storage for
  durable job state, concurrency/queue admission, provider-call reservations,
  token reservations and estimated/unknown spend.
- Reserved the call ID, conservative spend and tokens in a transaction before
  provider dispatch. Duplicate attempt IDs cannot dispatch again. Confirmed
  usage reconciles the reservation; ambiguous timeouts, cancellation and
  process recovery retain a nonzero reservation and become visibly unknown.
- Added atomic per-workspace/global running and queue limits, per-workspace
  token budget, existing session call/time bounds, and an operator-configured
  global inference-spend ceiling. Cloud inference requires the explicit
  SIGMA_CLOUD_OPENAI_API_KEY; no local key or ChatGPT account fallback occurs.
- Queued sessions without a provider attempt can be scheduled when an owner
  reconnects. A recovered running call is marked interrupted/unknown and is
  never automatically replayed. Existing explicit pause/resume/stop controls
  remain in use.
- Blocked cloud proposal, agentic-proposal, paper-generation and text-conversion
  inference routes until they have their own durable budget accounting. Local
  mode remains unrestricted and unchanged.
- Documented configuration and recovery semantics in docs/CLOUD-AUTH.md and
  recorded actual verification and limitations in docs/STATUS.md.
