## #95 — paused-session clarity

- The session UI displays the saved backend message, current action, typed
  failure/interruption cause where available, and a next safe action.
- The real-Chrome fixture covers manual pause, backend restart/provider
  interruption, context, wall-clock, cost, account/connection, project/strategy,
  and unknown guarded states. It checks close/reopen persistence, visible
  guarded-resume errors, desktop/390px layout, and no session-start request when
  opening a paused session.
- No interrupted call is retried automatically; the guidance warns that a
  dispatched request may still consume allowance.

## #125 — saved AI papers library

- Saved drafts are visible near the top of the paper dialog with a title, saved
  date, per-version TXT/PDF downloads, and inline PDF opening in a new tab.
- Saved HTML is collapsed by default and rendered as escaped text. Removing a
  saved draft requires visible confirmation; deletion checks project identity
  and removes only that draft's JSON/PDF artifacts. The UI updates immediately.
- TXT is derived from the immutable paper record without a model call. Cross-user
  text/PDF/download/delete access is denied by the API.
- The real-Chrome check covers desktop/mobile layout, hostile HTML, text/PDF
  payloads and headers, new-tab link, confirmation/cancel, per-version cleanup,
  and zero generation POSTs.
