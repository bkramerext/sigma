## Changes

Current Understanding offers **Infer strategy #n**, which derives one useful direction from current findings and source-linked session evidence, validates it, and immediately saves it through the shared strategy service with model/reasoning provenance. Generate retains its proposal/review/accept flow. Accessible in-app tooltips explain both actions.

Inference request state is held in a durable per-project ledger. Strategy provenance links a committed inference to its request so recovery works if the process stops after save but before ledger completion. Retries and restarts inspect current authoritative project state, including edits or removals; they do not return an old ProjectView. A provider dispatch whose result is ambiguous is terminal and is never silently repeated. Cancellation records a request, reconciles durable state, and does not claim that nothing was saved. A common project write lock serializes the final Current Understanding, session evidence, project setting, account, and strategy-history check with all corresponding writes and the actual strategy commit.

Backend adversarial coverage includes provider refusal/HTTP and timeout failures, strategy write failure and retry recovery, account/history/settings changes in flight, concurrent requests, lock-boundary races, cancellation before dispatch and during dispatch, persisted replay after removal and restart, and sponsored call/spending accounting. The Chrome fixture forwards to the real inference endpoint and uses a deterministic local OpenAI-compatible mock provider; it tests successful save/replay after removal, binding rejection before dispatch, terminal provider failure retries, count/reveal/removal, keyboard use, tooltip accessibility, and mobile visibility.
