## Change

Added typed `call.preflight_failed` audit events for branch-local work that
fails before provider dispatch. Events identify `strategy_id`, `strategy_title`,
`role`, `failure_stage`, `failure_kind`, and `dispatched: false`. Event messages
are generic and do not include raw exception messages, request content, or
credential data. Covered context assembly, project snapshot/binding, account
verification/binding, and model configuration preflight.

Added a mixed concurrent-wave regression: one branch fails at project snapshot
preflight while its sibling completes an Investigator call. The regression
asserts the branch/role attribution, no step for the failed branch, the sibling's
completed persisted output, and exactly one counted dispatch. Existing
configuration preflight failure and timeout/resume regressions now assert the
new metadata as well.
