## Implemented

- Removed the per-session six-call and `$0.25` replacements from sponsored
  research admission. Saved Project Settings limits now govern the session;
  account allowance, global ceiling, cost reservation, and the 15-minute
  hosted/sponsored runtime cap still apply. An unset sponsored session cost
  limit returns an actionable settings message.
- Hosted and local Project Settings expose the required estimated-cost limit
  for sponsored research. Configured duration persists as entered while the
  runtime deadline uses the applicable cap.
- Restored the local sponsored account's default global spending ceiling to
  `$0.25`; an explicit `SIGMA_CLOUD_GLOBAL_SPEND_CEILING_USD` still overrides it.
- In the supported local ChatGPT flow, explicitly disconnect before returning
  to sponsorship. Failed sign-in or disconnect does not silently change the
  funding source. Sponsored allowance records remain intact while personal
  inference is selected. Hosted personal authorization remains disabled; no
  hosted OAuth bypass was added.
- Model catalog 401/403 errors disable model selection and show the auth state;
  temporary provider failures preserve editable preferences as unverified.
- Session termination diagnostics distinguish session cost/token caps from
  hard account/global ledger refusals, with cycle/call counts and clear notice
  when a Skeptic call was never dispatched.
- Added deterministic regression coverage reproducing the former 1/6-call
  budget failure, hard-ledger refusal, token diagnostics, hosted sponsored cost
  setup, and local account transitions/model availability.
