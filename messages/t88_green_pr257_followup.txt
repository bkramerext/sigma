## Changes

- Standardized the Google and ChatGPT pill dimensions on Home and Project:
  34px height with 12px inline padding at desktop widths; 28px height with
  9px inline padding at narrow widths; 13px vertical gap and aligned left
  edges. Disabled project controls retain the established text color.
- Removed the native browser tooltip from the Sigma project logo. The custom
  tooltip appears relative to the cursor and remains at its initial position
  while the pointer moves over the logo.
- Kept the project header shorter, removed the separate Back to home action,
  and routed Home navigation through the Sigma logo.
- Kept category-level running status visible only while its Home Recent
  category is collapsed. Updated the browser check to use logo navigation and
  verify the indicator's visible/hidden states.
- Kept Suggesting… as a plain live status with the hourglass treatment and
  removed the redundant findings action. Removed Fork strategy from findings.
- Bounded strategy-suggestion context by summarizing source-linked current
  understanding, preserving the project question and existing strategies, and
  reporting omitted findings, changes, questions, failures, and limitations.
  This allows large project histories to stay within the request bound without
  presenting omitted records as examined evidence.
- Updated mock-auth browser assertions to the shipped Home actions and the
  13px pill gap. Added exact desktop/narrow pill dimension and padding checks,
  tooltip behavior checks, and clean pill/tooltip crops. Waits now confirm the
  displayed mock allowance/provider scenario before the simulated research
  starts; this makes the provider-unavailable acceptance deterministic.
- No authentication, authorization, workspace, funding, or provider runtime
  behavior changed. The strategy-suggestion context change is request
  construction only and is covered by bounded-context tests.
