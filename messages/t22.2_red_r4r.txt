Implemented opt-in Google OIDC authentication and invitation-based access control for cloud-hosted SIGMA. Google ID tokens are signature- and claims-validated; access requires an exact email invitation, exact verified email domain, or configured bootstrap administrator. Sessions are opaque, server-side, expiring, and revalidated against current grants on protected API requests. Administrators can add and revoke access entries through the copper/dark Access Management UI. Google identity remains separate from local ChatGPT authorization and AI-provider billing. Cloud auth is disabled by default.

The unauthorized-account flow displays “Access not yet granted” after valid Google authentication without authorization. It offers Explore Demo, a prefilled mailto invitation request to the configured administrator contact, and Use Another Account. It does not reveal access rules. `/demo` is only the no-workspace handoff; the curated read-only Demo remains parent T22 work. Private APIs remain protected for unauthorized identities.
