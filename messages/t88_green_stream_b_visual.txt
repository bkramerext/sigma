## Findings and corrections

- At desktop Project width, the local mock identity selector occupied an
  implicit grid column and widened the page beyond the viewport. It now spans
  the controls row and uses a capped width; at narrow widths it fills only the
  available control width.
- On a short/narrow Project viewport, the consolidated account dialog could
  be taller than the available space on either side of the identity pill and
  overlap the pill. Placement now chooses the side with more room, caps the
  dialog to that available height, and preserves a visible gap. The dialog
  remains internally scrollable.
- On narrow Home, the project list could paint over the identity pill. The
  Home top line now has a local stacking context above the project content.
- Expanded the two real-Chrome browser checks to verify dialog anchoring,
  viewport bounds, focus, no horizontal overflow, one identity pill, and
  screenshots across the requested identity states and page types. Corrected
  the denied-state desktop capture to explicitly restore desktop viewport size.
- No auth, authorization, workspace, funding, or provider behavior changed.
  The only component logic change computes the dialog's visual placement and
  available height.
