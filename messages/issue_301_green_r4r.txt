## Changes

- Log now opens via a normal new browser tab (`target=_blank`) with stable `<project>, Session <n>` title. The page continues independent single-flight polling.
- Log controls use SIGMA secondary button styling. `Download` replaces “Download Log”; `Jump to end` appears only off-bottom and immediately returns to the latest entry, while polling continues at any scroll position.
- Play/Stop share equal 28×28 hit targets; Resume tooltip is `Resume session #n`.
- `src/sigma/session_log.py` writes human-readable Markdown events with request/response details grouped per provider turn and a collapsed canonical JSON record for durable debugging. Download uses a presentation rendering from canonical frames; raw event records remain intact and the on-disk log remains append-only. Long response-wire blobs are summarized in the downloadable presentation to avoid huge lines while full captured event data remains persisted.
- Legacy malformed display math is normalized in the app Markdown renderer. Export rendering repairs unclosed math blocks and escapes unmatched currency delimiters. This does not mutate canonical stored event data.
- Browser checks and focused tests cover tab/polling/scroll/download behavior, standard button accessibility and dimensions, real FastAPI/storage integration with deterministic events, and malformed math rendering.
