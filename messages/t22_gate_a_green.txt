Remaining dependency / limitation

Gate A's workspace ownership checks cover the private project and research-data
routes reviewed in the current API. Gate B is still needed before hosted research
execution is deployment-ready. Cloud auth blocks `/api/ai/*`, but model-backed
project routes can still use a process-level provider context if configured.
Proposal generation, session start, paper generation and text conversion need
per-user provider authorization and budgets before a cloud pilot. This was not
implemented in Gate A, and no provider calls were made. Public Demo and cloud
deployment are also outside Gate A.
