## What changed

A researcher can inspect a saved open obligation or write a bounded follow-up,
inspect full source artifacts/IDs, select relevant cross-strategy evidence,
record a rejected transfer, edit the question, and explicitly approve a separate
strategy. Approval preserves parent/obligation/source lineage and uncertainty;
it does not run research. Original strategies, sessions and Conclusions remain.

The shared continuation service publishes an immutable bounded companion packet
under the project write lock before its strategy is published. A new session
validates the approved approach and source integrity, freezes the packet, sets
the approved question, and supplies its exact evidence to existing actual role
dispatch and request auditing. Recovery uses that session snapshot. Coordinator
decisions retain selected packets and completed role reviews.

Each role reviews accepted source IDs exactly once. Delivery, acknowledgment,
reported plan change and verified resolution remain distinct. A saved local
counterexample must be treated as a negative constraint and cannot be rejected
or deferred. A reported changed plan requires a concrete next test. This is a
structural safeguard, not semantic verification of arbitrary free text.
Original scoped obligations are never automatically retired by a fork.

New Outcome/Conclusion text exposes lineage, source links, reported uptake,
rejected transfers and remaining gaps. The five original subset session exports
compare equal before/after. The first new session also revealed a reader defect:
`sequence.json` allocation metadata was counted as unavailable research. The
reader now excludes that known metadata file.
