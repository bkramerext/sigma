Implemented the coordinator clarification. The user-facing fake administrator
switch, preview middleware, preview documentation and fake-preview browser test
are removed. There is no simulated-admin or mock-cloud mode. `./sigma start
--nav` is supported; with `SIGMA_CLOUD_BOOTSTRAP_ADMIN_EMAIL` set and OAuth
credentials configured, the launcher automatically enables real loopback Google
OIDC. With no bootstrap email, normal local startup stays in its prior local
single-user mode. OAuth secret, bootstrap email, auth database path and contact
email are kept out of the Vite process environment.

Local Google configuration is documented in docs/CLOUD-AUTH.md. It covers the
OAuth consent screen, Web application client, authorized origin and exact
callback URI, the actual Gmail export in ~/.bashrc, OAuth client ID/secret in
the ignored checkout .env, and the exact source-and-launch command. Local
authentication is explicitly identified as local SQLite state; it does not
claim to edit hosted account rules. The existing verified-email and immutable
Google-subject binding, OIDC/PKCE/state/nonce/CSRF/session validation and
server-side authorization checks are preserved.
