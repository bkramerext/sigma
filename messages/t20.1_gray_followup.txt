T20.1 follow-up — Gray

The UI follow-up is implemented on a branch from the merged T20.1 main commit.
It carries the requested research-session limit changes through the frontend,
shared backend validation, persistence, and enforcement. Existing saved values
remain intact. Session duration accepts minutes, hours, and days and is stored
as backend minutes. Defaults are 30 agent calls, 60 minutes, 12,000 output
tokens per call, and 3 Skeptic iterations with a 1–5 range. The proposed $5
budget remains out of scope.

Home Recent and Samples are grouped by project type in an internally scrolling
list. Recent shows at most four projects per category, bolds the most recent,
and reopens with only the active project's category expanded. Selecting the
active tab again collapses or expands all categories. Recent and Sample rows
omit duplicate category details and use matching Inter 13px title styling;
ordinary rows are regular weight and only the most recent Recent title is
bold. The Open Project Cancel button follows the dialog title. Tooltip delay
and hide-until-rehover behavior were also refined.
