## Review scope

This branch implements the sponsored allowance and local force-mode behavior,
invitation/reload dialogs, welcome message, administration table changes,
session progress text and toast cap. The sponsored pill displays the balance
from the signed-in account's local ledger, with a custom hover/focus/mobile
explanation. Server checks enforce eligibility, provider choice, and spending
limits. Hosted `SIGMA_CLOUD_FORCE_SPONSORED_MODE` remains default-off.

Local sponsored inference uses the designated `zetacontinuation@gmail.com`
ChatGPT sponsor by default, even when `SIGMA_CLOUD_INFERENCE_PROVIDER` is
unset. The signed-in member's ChatGPT session is not used. Connection checks,
provider credential validation and ledger job records share this selection.
Local spending is reserved against the member's configured grant. `--sponsored`
does not enable `--mock-auth`; mock identities and the simulated `$25`
allowance still require `--mock-auth` explicitly. At zero allowance, the pill
offers **Reload me!**.

The welcome appears on each fresh page entry for an eligible signed-in user,
but not on browser refresh. It starts with “Welcome to SIGMA.” and one of 100
distinct curiosity-themed lines. Invitation and reload requests remain
administrator-reviewed. Other changes include Privacy Notice return paths,
SIGMA action-button styling, invitation Add/Remove actions and row filtering,
compact scrollable authorized-user rows, five visible toasts with oldest-first
eviction, and the 50-word running-session summary with fallback text.

Configuration and rollback are documented in `docs/GETTING_STARTED.md` and
`docs/CLOUD_DEPLOYMENT.md`. Rollback disables the hosted flag and restarts using
the guarded release procedure. Production was not enabled.
